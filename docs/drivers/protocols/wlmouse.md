# WLMOUSE 鼠标协议（MacPulse 实现）

命令集跟 WLMOUSE 官方网页驱动 WLMOUSE HUB（gm.wlmouse.gg）发的一致，型号限制取自网页驱动的型号表 `env-models.json`，只收录“新协议”型号（命令带配置号）。实现在 `Source/WLMouse.swift`，机读型号表在 `data/wlmouse-models.json`。实机验证过：花•兽 Mini PRO，8K 接收器（PID `0xA868`）。

## 接口

- VID `0x36A7`。接收器和有线鼠标各有自己的 PID，见型号表的 `pollingRatesByProductId` 和 `wiredProductId`。
- 命令通道：**Usage Page `0xFFFF`，Usage `0x00`**，64 字节 Feature 报告，没有 Report ID：

  ```
  06 FF FF  09 00  A1 01  09 00  15 00 25 01  75 08  95 40  B1 02  C0
  ```

- 有些型号还有一个 512 字节的同类通道，用来驱动屏幕，不要用。按“最大 Feature 报告 64 字节”筛选。
- macOS：`IOHIDDeviceSetReport` / `IOHIDDeviceGetReport`，类型 Feature。Windows：`HidD_SetFeature` / `HidD_GetFeature`（或 hidapi 的 `hid_send_feature_report` / `hid_get_feature_report`），缓冲区前面加一个 `0x00` Report ID，共 65 字节。

## 请求

64 字节，除下面几位外都是 0：

| 下标 | 值 |
|---|---|
| 2 | `0x02` |
| 3 | 参数长度 |
| 4 | 命令组（0 或 1） |
| 5 | 命令码。读 = 写的命令码 \| `0x80` |
| 6… | 参数（最多 58 字节）。按配置区分的命令，第一个参数是配置号（从 1 开始） |

## 回复

发出请求后每 30 ms 读一次 Feature 报告，最多 15 次；整个请求最多重发 5 次。有的系统读回来少了开头的 0 字节，先规整：如果第 0 字节就是 `0xA1`，在前面补一个 0。规整后：

| 下标 | 含义 |
|---|---|
| 1 | 状态：`0xA1` 完成；小于 `0xA1` 还在忙，继续读；大于 `0xA1` 没接受，重发 |
| 6 | 回显的命令码，要和请求一致 |
| 7 | 不带配置号的读取，值在这里 |
| 8… | 带配置号的读取，值从这里开始 |

## 命令表

| 组 | 读 | 写 | 内容 | 编码 |
|:-:|:-:|:-:|---|---|
| 0 | `0x83` | — | 电量 | 见下文“电量” |
| 0 | `0x85` | `0x05` | 当前配置 | 1 字节，从 1 开始 |
| 0 | `0x86` | — | 配置数量 | 1 字节 |
| 0 | `0x8E` | `0x0E` | 配置名（参数：配置号） | `r[8]` 长度，`r[9…]` GBK 字节，最多 30 字节；写：`[配置号, 长度, 字节…]` |
| 0 | `0x88` | `0x08` | 去抖动（ms） | 0–15 |
| 0 | `0x87` | `0x07` | 休眠时间（秒） | 2 字节大端，65535 = 不休眠 |
| 1 | `0x81` | `0x01` | DPI 档位 | 读参数 `[p, 6]`；`r[8]` 档数，之后每档 4 字节 `xHi xLo yHi yLo`。写：`[p, 档数, 每档 4 字节…]`，长度 26 |
| 1 | `0x82` | `0x02` | 当前档位 | 1 字节，从 1 开始 |
| 1 | `0x80` | `0x00` | 回报率 | 见下表 |
| 1 | `0x88` | `0x08` | 静默高度 LOD | `[编码, 模式]`，编码见下表 |
| 1 | `0x89` | `0x09` | Motion Sync | 0 / 1 |
| 1 | `0x84` | `0x04` | 直线修正 | 0 / 1 |
| 1 | `0x8A` | `0x0A` | 波纹控制 | 0 / 1 |
| 1 | `0x8B` | `0x0B` | 高速模式 | 0 / 1 |
| 1 | `0x93` | `0x13` | 竞技模式 | 0 / 1，要先开高速模式 |
| 1 | `0x8D` | `0x0D` | X / Y 分别设置 | 0 / 1 |
| 1 | `0x94` | `0x14` | 角度微调 | 有符号，−30…30 |

组 1 的读写都带配置号 `p`。切换配置（组 0 `0x05`）后其他值都会变，MacPulse 切换时不同时写别的，切完重新读一遍。

**回报率编码**：125 → `0x08`，250 → `0x04`，500 → `0x02`，1000 → `0x01`，2000 → `0x20`，4000 → `0x40`，8000 → `0x80`。读到 `0x10` 按 1000 处理。

**LOD 编码**：小于 1 mm 时是 `十分位 | 0x80`（0.7 → `0x87`），整毫米是毫米数（1 → `0x01`，2 → `0x02`），1.x 是 `1 << 4 | x`（1.2 → `0x12`）。

## 电量

组 0 `0x83`，参数长度 2。回复格式和网页驱动一致：`… A1 … 02 … 83 充电 电量`，有时整体错开一个 Report ID 字节：

- `r[1] == A1 && r[4] == 2 && r[6] == 0x83` → 充电在 `r[7]`，电量在 `r[8]`
- `r[0] == A1 && r[3] == 2 && r[5] == 0x83` → 充电在 `r[6]`，电量在 `r[7]`

充电 `1` 表示正在充电。鼠标休眠时接收器回 0，不算读数。

## 写入流程

和键盘一样先改草稿，点“应用”时只发送变了的字段，写完整套读回来逐项核对：配置名、DPI 档位、当前档位、回报率、LOD、去抖、Motion Sync、直线修正、波纹控制、高速、竞技、角度微调、休眠。关掉高速模式时竞技模式也一起关。

## 实测

`devices/wlmouse/` 里有接收器的 HID 接口、报告描述符和 `--mouse-dump` 的只读输出。
